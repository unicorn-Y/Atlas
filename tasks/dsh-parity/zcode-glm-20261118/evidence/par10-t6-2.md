## 3. 交付内容

### 3.1 纯函数模块 `core/atlas/plugins/version_facts.py`

- `newer_versions(current, available, *, include_prerelease=True) -> list[str]`
  - `available` 中 `> current` 的 SemVer 版本，**严格大于**、稳定升序；
  - 非法 `available` 项跳过（与 DSH 的 `semver.valid` 过滤同义）；
  - 非法 `current` 抛 `ValueError`（明确错误，不产生误导性的空列表）；
  - `available` 可为单个字符串；也接受 DSH 风格 answer 对象（`{"versions": [...]}`，
    `versions` 为字符串或数组）；`include_prerelease=False` 可排除预发布；
  - 自包含 SemVer 2.0.0 解析/比较（不用 `packaging.version`，因为 npm 的
    `1.0.0-beta.1` 不是合法 PEP 440 版本）；
  - 忽略 build metadata（`1.0.0+build` 不大于 `1.0.0`），接受 `v`/`=` 前缀；
    `sorted` 稳定，同优先级项保留 packument 顺序。
- `version_facts(metadata, *, version=None) -> dict`
  - 接受 npm packument（`versions` + `dist-tags`）或单个版本对象；
  - 选择顺序：显式 `version` → `dist-tags.latest` → 最高 stable → 最高 prerelease；
  - 返回恰好 `{"peerDependencies": ..., "deprecated": ..., "dsh": ...}`：
    - `peerDependencies`：仅字符串键值，缺字段/非对象/非字符串值 → `{}`；
    - `deprecated`：非空字符串原样、`True`、其余 → `False`；
    - `dsh`：对象浅拷贝，缺字段/非对象 → `{}`；
  - 非对象 metadata、非法 packument、显式版本不存在 → `ValueError`；
  - 纯函数：无网络、不读环境变量/凭据、不修改输入。
- 辅助公开：`is_valid_version`、`is_prerelease`、`select_version`、常量
  `VERSION_LIST_FIELDS` / `VERSION_FACTS_FIELDS`。

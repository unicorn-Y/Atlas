## 3. Pricer 契约与生产接线

### 3.1 `token_meter.route_image_pricer`

```python
route_image_pricer(model_config) -> Callable[[route, images], Sequence[Mapping]] | None
```

回调逐张返回一条 `{"visual_tokens": int >= 0, "text": str}`，与 `images` 等长、同序。

- 模型条目显式声明 `image_pricing` 时保持旧语义:整数或
  `{"visual_tokens": int, "text": str}` 对所有图片统一计价(显式配置优先)。
- 未声明时，DeepSeek 条目(provider 以 `deepseek` 开头，或 `wire_model/model/
  model_id/id/native_model/litellm_model` 命中 `deepseek-`/`deepseek/`/
  `/deepseek-`/`/deepseek/`)返回**逐图网格 pricer**:按每张图片自己的内在尺寸
  计算 `visual_tokens`，`text=""`，base64 不再进入文本估算。
- 未识别尺寸/远程 URL/未知格式:单图保守按 `MAX_IMAGE_TOKENS=1024`。
- 其他模型未声明价格仍返回 `None`，保持旧固定启发式;非法配置日志脱敏
  (`token_meter.image_pricing_ignored`，只含原因不含 payload)后返回 `None`。

### 3.2 `price_surface_nodes` / `_replace_image_parts`

- 协议不变:`image_pricing(route, images)` 收到路由与按位置排序的所有图片出现;
  数量不符、负值、非字符串 text 仍显式报错。
- `_replace_image_parts` 在文本估算前把图片块替换为占位文本(网格 pricer 用空串),
  **不修改输入消息**;新增支持 Atlas `_multimodal` 信封(图片在 `content` 子列表，
  文本侧仍只按原 `text_summary` 计)。
- 既有逐节点结构**保持不变**:`{"seq", "tokens", "heuristic_tokens"}`。
  图像合计只加在结果顶层 `"image_tokens"`(以及 `surface_tokens`)，供
  `loop.py` 的用量行消费;不新增 per-node 键。

### 3.3 两条预算路径

- `ModelRouter.complete()`(辅助请求):`_request_budget_estimate`。纯文本请求
  继续走原 `"\n".join(str(content))` 估算，逐字节不变;存在图片时先
  `strip_image_payloads` 再做文本估算，仅 DeepSeek 路由叠加
  `deepseek_message_image_tokens`。异常回退旧估算，计量不阻断请求。
- `model_call.complete_stream()`(主对话):`_budget_input_estimate`。纯文本仍
  `json.dumps(messages)` 原样估算;图片消息先投影掉 payload 再 dump，DeepSeek
  再叠加网格合计。异常同样回退。

### 3.4 usage 优先与展示

- 辅助请求:`report_auxiliary_usage` 读取 provider `prompt_tokens/input_tokens`
  后 `budget.record(...)`，实际 usage 结算预留。
- 主对话:`complete_stream` 以流末 `last_usage` 构造 usage row 并 `budget.record`。
- kernel:`record_model_attempt` 先取 `attempt_usage` 的真实 input/output;
  `surface_token_estimate`、`surface_image_tokens`(本包新增)与 anchor 仅作
  辅助遥测，不覆盖 `input_tokens`。
- 前端:`UsageSummary.visual` 累计 `surface_image_tokens`，在用量明细里显示
  “图像视觉 约 N”(title 注明按尺寸网格估算、已包含在输入 token 中);总输入/
  输出/费用仍来自 provider。

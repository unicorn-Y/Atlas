实现要点：

- `render_office` 对 docx/pptx 先 `from docx import Document` / `from pptx import Presentation`；仅 `ImportError` 时进入降级。
- docx 降级：`zipfile` 读 `word/document.xml`，按 `w:body` 顺序输出段落、标题（`w:pStyle=HeadingN`/`Title`、`w:outlineLvl`）、表格（`w:tbl/w:tr/w:tc`），并处理 `w:sdt`（递归深度上限 32）；HTML 沿用现有 `office-html` 风格。
- pptx 降级：按 `ppt/slides/slideN.xml` 的数字序号自然排序（数字排序，非字典序），输出每个 `<section class="slide" data-slide="N">`、标题 `h2`、正文 `div[data-shape-id] > p`，与前端解析器契约一致。
- 边界：zip 成员数 ≤ 512；单成员声明解压 ≤ 16 MiB、实际读取同样截断；总解压 ≤ 64 MiB（声明 + 实际累计）；文本 ≤ 200,000 字符（超出截断并标注）；幻灯片 ≤ 200 页（超出截断并标注）。
- 安全：不向磁盘解压；拒绝绝对路径、`..`、`.`/空路径段、盘符、重复成员、符号链接成员；XML 优先 `defusedxml`，其后加载 stdlib 并预拒绝 `DOCTYPE`/`ENTITY`。
- 失败语义：依赖缺失且降级失败时抛 `OfficeDependencyMissingError(ValueError)`，消息以 `dependency_missing:` 开头并附 `unsupported:` 原因；worker 转为 JSON error，路由映射 422，不泄漏 `ModuleNotFoundError`，不产生 500。xlsx 缺 `openpyxl` 同样给出 `dependency_missing:`。

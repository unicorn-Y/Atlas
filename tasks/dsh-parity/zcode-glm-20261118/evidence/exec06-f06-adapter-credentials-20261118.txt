A. DSH DeepSeek adapter:双凭据路由 + Files API + 图像计价
================================================================================
Files API(packages/llm/llm-deepseek/src/files-api.ts):
- 常量 :9-30:MIN_FILE_EXPIRY_SECONDS=3600、MAX_FILE_EXPIRY_SECONDS=2,592,000(30d)、
  MAX_FILE_UPLOAD_BYTES=128MiB、MAX_STORED_FILE_COUNT=10,000、MAX_STORED_FILE_BYTES=25GiB。
- DeepSeekFileObject{id,bytes,createdAt,filename,expiresAt?};分页 {firstId,lastId,hasMore}。
- DeepSeekFilesError 按 HTTP 401/403→AUTH、429→RATE_LIMIT、5xx→SERVER、其余→FILES_API;
  isFilesQuotaError 检测 quota/storage/stored files/file count/too many files。
- DeepSeekFilesClient:直连配置根、拒绝重定向以免凭据离开源;非法 JSON→INVALID_RESPONSE。
File store(packages/llm/llm-deepseek/src/file-store.ts):
- MAX_IMAGE_BYTES=32MiB/图;DeepSeekUploadIndex 做用户级 durable file-id 复用;
  同名上传(attachmentId+variantId 前缀)共享一个 AbortController/promise;
  最后一个 waiter 取消才 abort;过期+refresh margin 触发重传;配额错误→有界清理批+重试。
图像计价:
- image-tokens.ts: 按提供方公开的 token 网格把宽高切成 token cell,单图上限 1024 tokens,
  小图不放大;request-pricing.ts 在发送时用实际尺寸计价,路径解析在计价时发生。
凭据路由:
- llm-deepseek-account/src/index.ts: provider 'deepseek-account',头 x-dsh-auth-token;
  未登录→ACCOUNT_SIGN_IN_REQUIRED;401→ACCOUNT_TOKEN_INVALID 并作废 token;
  配额→ACCOUNT_QUOTA_EXCEEDED;模型目录 cache 按列表加载。
- credentials/deepseek-account/src/index.ts: 浏览器授权(attempt/callback/超时)、
  device token、logout 重试(最多 5 次,指数退避)、通知流、account signed-out 事件。

D. 验收标准(二值)
================================================================================
Files API:
A-1 同一 attachment/variant 第二次请求命中索引,不再上传;跨进程可用(durable index)。
A-2 过期前 refresh_margin 触发重传;上传/列表 401→AUTH,429→RATE_LIMIT,5xx→SERVER。
A-3 配额错误触发一次有界清理+重试;超过 32MiB/图拒绝;超过 128MiB/上传拒绝。
A-4 文件 id 只发送到配置 origin,重定向被拒;非法响应→INVALID_RESPONSE。
图像计价:
A-5 给定宽高返回与 DeepSeek 网格一致 token 数(单图≤1024,小图不放大);
     请求实际尺寸与计价一致。
账户:
A-6 未登录时 deepseek-account 路由报 ACCOUNT_SIGN_IN_REQUIRED;401 后 token 作废并
     要求重登;配额错误映射 ACCOUNT_QUOTA_EXCEEDED;登出失败按有界退避重试。
A-7 账户与 API-key 两路由并存,选择不影响既有 custom/OpenAI 兼容路径。
复验:单元 fixture(HTTP mock 记录上传次数/头/尺寸)+ 真实受控 provider 一次(需凭据,
    未授权时不消耗用户配额)。

### 3.2 可见入口

1. **设置 → 快捷键**（现有导航项 `shortcuts`）→ `ShortcutsPanel` 顶部卡片“快捷键参考 / 打开参考 Ctrl+/”按钮（`data-open-shortcut-reference`）。点击派发 `atlas:open-shortcut-reference`；host 打开参考层。
2. **全局键盘** primary+/：`main.tsx` 渲染的 `ShortcutReferenceHost` 监听 window keydown capture；普通页面、输入框、终端类焦点均可打开（录制态除外）。
3. **关闭**：再按 primary+/ 关顶层；`Esc` 先取消录制、再关层；点遮罩或右上角关闭；设置对话框被关闭时若参考层仍叠在其内，MutationObserver 判定锚点断开并关层。
4. **平台适配**：macOS 用 `metaKey + Slash`，Windows/Linux 用 `ctrlKey + Slash`；按钮与层内提示分别显示 `⌘/` 或 `Ctrl+/`。

### 3.3 模态互斥（DSH `modals: ['settings','shortcuts']` 语义）

- 参考层打开前扫描 `[role="dialog"], [role="alertdialog"]`（Radix `Dialog` 不带 `aria-modal` 属性，因此以 role 为准），排除自身：
  - Settings（含 `aria-label="关闭设置"` 标记）→ **允许**，参考层 portal 到 Settings 的 Radix Content 内部（`absolute inset-0`），与设置面板共享同一个焦点陷阱；表现为“参考层叠在设置模态上”。
  - 其它任何 dialog（Palette、KeymapDialog、transcript、recap 等）→ **blocked**，显示 `data-reference-blocked="modal"` 可见提示，不打开参考层。
- 参考层已是顶层时：再次 primary+/ 关闭它；`Esc` 关闭；`matchShortcut` 命中的 App 全局动作与 App 特判键（`?`、Ctrl+T、Ctrl+P、Ctrl+Alt+Space、Alt+Shift+A 等）在 capture 阶段被 `preventDefault + stopPropagation + stopImmediatePropagation`，不会叠加设置/面板/命令面板。
- 录制态优先：事件目标位于 `[data-shortcut-recorder]` 时 host 立即返回，全局 toggle 不触发；录制器自己消费按键（探针里把 Ctrl+/ 录进 newTask，参考层保持关闭）。

### 3.4 共享控制器（探针发现并修复的真实问题）

首版参考层与设置面板各自 `new KeybindingsSync(...)`。Electron 探针先经参考层保存 palette、再经设置面板保存 newTask 时，设置面板仍持挂载时读到的旧 revision，触发 409 并显示“保存冲突”。这与 DSH 单一 `shortcutsStore` 语义不符，也属于同窗自冲突。

修复：`KeybindingsProvider` 由 `main.tsx` 包住 `<App />` 与 `<ShortcutReferenceHost />`，两处 `useKeybindings(apiBaseUrl)` 取得同一控制器（同一 `KeybindingsSync`、同一 revision/pending/conflict/localStorage 写入）。修复后探针两步连续保存：`expected_revision` 从 `rev-1` 变为参考层保存后的 revision，无冲突提示；新增单测 `shares one KeybindingsSync ... never self-conflict` 固定该行为。

- **模态判定采用 role**：`[role="dialog"], [role="alertdialog"]` 均视为 modal。若未来出现非模态的 `role="dialog"` 浮层，它也会阻止参考层；当前 Atlas 的此类元素（Settings/Palette/Keymap/transcript/recap 等）均为模态语义。

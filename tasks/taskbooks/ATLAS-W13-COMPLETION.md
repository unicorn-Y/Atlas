## 1. 语音（W06 暂缓的部分）
- 前端接 W06 已有的本地识别（`/api/asr/*`、WS `/ws/asr`，sherpa-onnx + SenseVoice）：语音按钮和语音通话界面用 AudioWorklet 采集 16 kHz PCM；模型没下载时提示下载并显示进度；`/api/asr/status` 不可用时才退回浏览器识别。
- **边说边干**（参考 ChatGPT 桌面端语音驱动 Codex）：语音指令直接派任务；Atlas 干活时用语音简短汇报进度（本机朗读，已有）；用户说话能打断朗读；说「停」停止当前任务。
- 语音合成可选接 sherpa-onnx 本地 TTS（中文自然度比系统朗读好），H `tools/tts_*.py` 参考。

## 2. 统一入口（F009）
- 输入框不再要求用户选模式：Atlas 自己判断是直接回答、先出计划再做、还是派子 Agent / 看板（参考 Claude 9 月合并聊天与 Cowork）。判断规则：一两步能完成的直接做；会改多个文件或耗时长的先出计划；可拆成独立子任务的走 W07 委派。用户手动选的模式优先。
- 后端：运行开始前用快模型做一次分类（结果写进 `run.started.data.route`），前端显示「Atlas 判断这是…」并允许一键改。

## 3. 远程子 Agent（A2A）
- 来源：H `plugins/platforms/a2a`；O `extensions/a2a`；Gemini CLI 远程 Agent。
- Atlas 可以把子任务派给 A2A 协议的远程 Agent（包括另一台机器上的 Atlas：主机 ↔ 笔记本，复用 W10 的设备配对凭据）；Atlas 自己也作为 A2A 服务端暴露（只在第二监听上、只认配对凭据）。
- 子 Agent 定义文件支持 `remote: {url}`。

## 4. 多人协作（只做用户自己用得上的部分）
- 对话「只读分享链接」已在 W10；本波加「协作链接」：受邀的人在网页上能看对话、发消息（作为插话进当前运行）。默认关闭，链接可撤销、可设过期。
- 渠道群聊接任务（参考豆包工作伙伴进飞书群）：W08 的飞书 / 钉钉渠道支持群里 @ Atlas 布置任务，只响应白名单成员。

## 5. 创作：图像、视频、音频
- 图像生成 / 编辑（W10 已接服务商）在对话里支持：多张候选、局部重绘、用作 PPT / 网页素材。
- 视频：参考 Manus Studio 的时间线剪辑思路，先做「按脚本拼接素材 + 字幕 + 配音 → 导出 mp4」（用 ffmpeg，本机安装检测），产物可在文件面板预览。
- 音频：文字转语音导出（播客 / 旁白）。

## 6. 无界面运行（F210）与共享状态（F201）

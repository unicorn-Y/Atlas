# CODEX-ATLAS-P10L-AUTONOMOUS-KNOWLEDGE-EVOLUTION

## Goal
Build the next autonomous knowledge evolution layer on top of governed advisory knowledge.

## Requirements
- Keep facts immutable and approval boundaries unchanged.
- Consume only approved advisory knowledge with complete provenance.
- Add deterministic evolution analysis and evidence tracking.
- Preserve auditability for every generated recommendation.
- No automatic promotion without explicit approval.

## Validation
- Add focused regression tests.
- Keep existing memory, quality, agent and planning contracts compatible.

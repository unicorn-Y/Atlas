# T1 preparation contract

Only tests/t1/** and the named SOL result/status files may change. No real participant execution during preparation. Workers share this worktree; do not revert others or commit independently.

Python 3.11+ stdlib harness. Task directory tasks/NN contains task.md, manifest.toml, check.py, rubric.md, fixture/ and solution/ (trusted reference overlay, never exposed to real participants). check.py takes positional workspace path, exits 0 iff solved. Optional setup.py takes workspace path; external repositories must use pinned immutable commits and a cache outside this repository. selftest.py verifies broken baseline fails and reference solution passes, including negative tampering tests.

Manifest keys: id (string), title, kind, allowed_changes (array of glob strings), protected_paths (array, default tests/**), timeout_seconds (number), multi_round (bool), capabilities (array). fixture is copied first, setup runs before git baseline; solution is a reference overlay. Tests newly added under explicitly allowed paths are permitted; original tests remain immutable. scenario.json optional: {"steps": [{"action": "prompt|plan|approve|checkpoint|rewind|steer|context", "text": "...", "name": "...", "trigger": {"event": "...", "after_seconds": 0.1}}]}. Record real action/events, never fabricate support.

participants/base.py exports RunContext dataclass(task_id, workspace: Path, task_dir: Path, prompt: str, model: str|None=None, timeout_seconds: float=120, config: dict default empty, scenario: dict|None=None), RunOutcome dataclass(exit_code:int|None, stdout:str, stderr:str, events:list[dict], duration_ms:float, error:str|None=None, unsupported:list[str] default empty). Adapter methods availability()->dict {available:bool,reason:str}, build_command(context)->list[str], run_once(context)->RunOutcome, parse_usage(outcome)->dict with nullable tool_calls/turns/input_tokens/output_tokens/cached_tokens/cost_usd, supports(capability)->bool, cleanup()->None. get_adapter(name, config=None) in participants/__init__.py. Fake follows same contract; config fake_mode success|failure|timeout|forbidden and fake_cost_usd.

Runner prep guard: real adapters require explicit --allow-real (default denied); --dry-run never invokes run_once or fixture network setup. Fake may execute. Unsupported task capabilities produce status unsupported (success null), not failure. ZCode generates manual instructions/template. Result fields per taskbook plus status, schema_version, model, usage_source, scenario_events. JSON schema and Python validation match. Logs sanitized for secrets. Resume fingerprint includes participant/track/model/task fixture/config; completed matching results skip. Budget accounts resumed spending and unknown cost cannot silently equal zero.

Fault proxy implemented separately under fault_proxy/, stdlib loopback HTTP fake OpenAI-compatible provider, no upstream network. Exports FaultProxy context manager with url, requests, faults sequence 429|500|disconnect then successful fake response, streaming supported. Fake task20 exercises local recovery only.

Worker ownership: runner owns run.py,harness/,schemas/,config.example.toml; adapters owns participants/ including fake and adapter tests under participants/tests/; fixtures workers own assigned tasks plus fixtures/ helpers uniquely named. Root integrates selftest.py, README.md, fault_proxy/, top-level tests and final artifacts.

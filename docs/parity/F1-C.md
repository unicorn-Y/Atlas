## 补充来源的纳入边界
- Hermes/OpenClaw 仅补“消息平台 Gateway 的策略/toolset/定时投递”和“执行节点配对后单独审批节点能力”。Atlas 已有 channels/devices 基础 API，本次补 UI/状态，不绕过原有权限审批。

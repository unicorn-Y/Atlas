# B-TC-06｜Files：文件树、预览与编辑器

实现提交：`d4a3d09` (`feat(files): complete workspace tree and editor parity`)

## 条目结果

- **B053 工作区文件树、Git 状态、右键复制路径/加入上下文 — 已完成。** 文件树和搜索结果沿用真实工作区路径；右键菜单现在可以复制相对/绝对路径、打开文件、显示目录并把文件加入 Composer 的 `@file` 上下文。上下文由现有 `context_files` 请求提交。目录状态按真实 Git porcelain 数据从子项聚合；文件、未跟踪文件及重命名目标使用 Git 返回的状态。
- **B082 从消息文件引用/差异文件在外部编辑器或 IDE 打开 — 部分完成。** 消息中的本地文件引用可右键用系统默认程序、VS Code、Cursor、Zed、IntelliJ IDEA 或 PyCharm 打开；改动面板可把文件交给所选 IDE；文件树和消息菜单可加入下一条消息上下文。Electron 主进程校验文件真实路径位于当前工作区内，并通过固定 allowlist 启动 IDE CLI。SSH 文件不提供本机打开。未实现任意未登记 IDE 命令和 IDE 当前活动文件的反向同步；Atlas 没有可读取这些外部 IDE 状态的 API。
- **B090 Codex 侧栏文件标签拖放排序 — 已完成。** `FilesPanel` 的已打开文件标签可拖放重排；顺序直接更新现有标签状态。行为依据 Codex 26.409 更新记录。
- **B104 内置文件编辑器磁盘冲突提示 — 已完成（本地文本文件）。** 文件源码视图可编辑并保存不超过 512 KiB 的文本文件。读取版本带 SHA-256；保存时后端比较当前磁盘哈希，版本不匹配则返回冲突，界面保留草稿并提示加载磁盘版本。加载磁盘版本会丢弃草稿。二进制、大文件和 SSH 文件不开放编辑。
- **B107 文件树 Git 状态标记 — 已完成。** 核实既有 `/api/workspace/tree` 本来就读取 `git status`，但重命名输出和目录状态不完整；现在使用 NUL 分隔 porcelain 输出映射单文件状态，并将变更聚合到父目录。非 Git 工作区没有虚构标记。
- **B108 文件树按名称搜索和刷新 — 已完成（已有能力核实）。** 文件名搜索通过工作区搜索接口返回真实文件；顶栏“刷新文件”按钮会刷新根目录和已展开目录。此项无需新增按钮。
- **B117 Markdown/SVG 源码与预览切换、换行/字体 — 已完成。** 文件面板已有 Markdown 源码/预览切换；源码编辑器加入换行和字体大小控件，代码块既有换行/字体控件继续生效。代码块现在支持受限 iframe 的 SVG 预览；未复制上游代码。
- **B129 PPTX 页码、缩略图、缩放、元素选择和导出 — 未完成。** 当前后端只生成静态 HTML 幻灯片内容（标题、文本和图片），没有稳定的幻灯片/元素模型或渲染端点，无法实现真实缩略图、元素选择和 PPTX 导出；添加这些控件会成为假交互，因此保留现状并明确限制。

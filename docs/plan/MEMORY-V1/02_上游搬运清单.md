## M4 召回排序：Generative Agents

- 论文：Park et al., *Generative Agents: Interactive Simulacra of Human Behavior*, 2023，检索打分 = recency + importance + relevance（各项归一化后加权）
- 参考：MemoryBank（Zhong et al. 2023）基于 Ebbinghaus 遗忘曲线的强化，即被回忆时增强
- V1 实现：S4 第 3 条的公式。在 `retrieval.py` 的注释中写明论文出处和本地改动（按 facet 设定半衰期、HIGH 下限、只影响排序）。

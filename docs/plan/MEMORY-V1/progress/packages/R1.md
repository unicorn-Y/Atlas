### 【回归 3 排查证据：既有顺序依赖与测试间状态污染】
- **现象**：`test_old_backfill_does_not_replace_current_state` 单独跑通过（`45 passed in 3.14s`），全库跑失败。
- **根因调查实证**：
  1. `tests/unified_memory/conftest.py` 中的 `svc` 是 `scope="session"` 的单例隔离服务，整套测试复用同一个 SQLite 数据库。
  2. `tests/unified_memory/test_conflict_resolution.py`（排在前面）在 `test_temporal_update_supersedes_old_interval` 中，向默认主体 `subject-default` 写入了一条记忆 `mem-fm-...`（内容为 "现在住深圳"，facet="FACT"）。
  3. `tests/unified_memory/test_temporal.py` 中的 `test_old_backfill_does_not_replace_current_state`（排在后面）同样使用默认主体 `subject-default`，在此主体下插入了当前状态记忆 `tp-sz-{tag}`（内容为 "现在我住在深圳，住哪都记录清楚{tag}"，facet="STATE"，valid_from="2026-08-01"）。
  4. 随后测试调用 `POST /v1/unified/recall`，查询 `query="现在住哪里"`。
  5. 在 `5ad0db8`（S4 Generative Agents 淡忘排序）引入前（ba86134 基线）：`_fulltext_channel` 平局决胜按 `recorded_at` 升序排列（2026-08-01 先于 2026-10-08），因此 `tp-sz` 偶合排在 `mem-fm` 前面，使得断言 `first["record_ref"] == refs["shenzhen"]` 侥幸通过。
  6. 在 `5ad0db8` 引入 Generative Agents 排序分后：
     - `score = w_rel*relevance + w_imp*importance + w_rec*recency_decay + w_use*reinforcement`
     - 规则规定 `STATE` 半衰期为 14 天（距今 68 天，衰减因子为 `0.5 ** (68 / 14) ≈ 0.034`），而 `FACT` 不衰减（`1.0`）。
     - 因此来自 `test_conflict_resolution.py` 的残留 `FACT` 记忆得分高于本测试刚插入的 `STATE` 记忆（2.468 vs 1.534），被排到首位。
  7. **结论**：这是典型的跨测试状态污染（共享 fixture + 硬编码相同 subject `subject-default` + 无独立租户隔离）叠加 Generative Agents 正常衰减排序逻辑造成的既有顺序依赖。`8ac2fff` 并未改动排序与召回；`test_temporal.py` 单跑完全通过。按任务书红线纪律，不靠 xfail/skip 掩盖，如实披露。

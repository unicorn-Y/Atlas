## 一、整改背景与缺陷根因

在独立审计 `AUDIT_K3.md` 中核实：
1. **ISSUE-02 (CRITICAL)**：`assemble_recall_context` 在生产代码中零调用（死代码）。`run_phases.py:519` 仍旧直接调用 `agent._memory._unified_recall_context`，绕过了画像块渲染、出处标号装配与新意图闸门；`run_phases.py:542` 仍直接调用旧正则 `atlas.memory.context.is_personal_memory_relevant`。
2. **ISSUE-05 (MEDIUM)**：`core/atlas/memory/recall_context.py:183, 194` 中硬编码了测试专用人名 `"老王"`。

后果：画像块（Profile Block）从未注入系统提示词靠前位置；相关记忆块未带 `[m:<ref>]` 标号与日期出处标记；基于语义向量嵌入 + 轻量规则的新意图闸门在生产回合中完全未生效。

## 二、整改措施与代码改动

### 1. 接通 `assemble_recall_context` 生产装配 (`core/atlas/agent/run_phases.py`)
- 在 `_phase_context` 中判断 `unified_enabled` 为真时：
  - 动态探测 `agent._memory._unified_or_none()` / `_unified` / `agent._memory` 获得统一记忆客户端对象；
  - 真正调用 `await assemble_recall_context(unified_target, state.message, recent_history=state.history, session_id=request.conversation_id)`；
  - 将装配结果调用 `to_context_dict()` 回写给 `state.context`。
  - 保留服务不可达降级分支，捕获 `ServiceUnavailable` 并记录告警日志 `memory.unified.recall_unavailable`。
- 在 `_build_messages` 中：
  - **系统提示词靠前稳定位**：在基础 `_agent.SYSTEM_PROMPT` 之后立即注入画像块（≤600 token）与引用规范 `PROVENANCE_SYSTEM_INSTRUCTION`，使画像稳定块能够在各大模型推理时最大化利用 Prompt Cache。
  - **建议记忆块装配**：检查 `state.context.get("relevant_memory_block")`。若存在，直接作为 `SystemMessage` 注入带 `[m:<ref>]` 标号、日期、状态（当前/历史/冲突）的相关记忆块（≤1500 token）。若不存在（旧测试桩场景），则保持既有 `_MEMORIES_PREFIX + json.dumps(memories)` 降级契约。
  - 在 `_hermes_turn` 中将 `"【本轮相关记忆】"` 纳入 `volatile_prefixes`，使其作为会话启动 advisory context 传入引擎。

### 2. 彻底移除旧正则调用，切到新意图闸门
- 移除 `run_phases.py:542` 中对旧正则模块 `from atlas.memory.context import is_personal_memory_relevant` 的导入与调用。
- 当统一记忆启用时，意图闸门由 `assemble_recall_context` 内部执行（语义向量余弦相似度 + 轻量规则匹配）；
- 当统一记忆未启用（本地降级模式）时，改调新闸门 `from atlas.memory.recall_context import is_personal_memory_relevant`。

### 3. 清理硬编码测试专用词与保留通用词说明 (`core/atlas/memory/recall_context.py`)
- **清理项**：彻底删除 `has_personal_cues_code` 和 `personal_keywords` 中出现的测试专用人名 `"老王"`。
- **通用词保留理由**：
  - 关系称谓（"女儿"、"儿子"、"老婆"、"老公"、"同事"）：属于中文通用家庭与社会关系称谓，任何真实用户都可能在对话中提及家庭成员，非测试场景专有名词。
  - 个人状态与时态问句（"住哪"、"住在"、"前几天"、"后来改成"、"多大"、"几岁"、"叫什么"、"适合我"）：属于自然语言中标准的个人背景询问、属性提问与跨轮状态变更通用句式。
  - 规范要求：全库排查已确认除 `"老王"` 外无其他测试场景专有名词。

### 4. 保持契约兼容 (`RecallContextResult.to_context_dict`)
- 兼容既有 `state.context["memories"]` 结构：对每一条装配记录补充标准化字段（`id`, `record_ref`, `key`, `value`, `content`, `category`），下游 `test_unified_memory_v1_reads`、`test_agent_run_phases`、`maintenance_context` 消费完全无损。
- 兼容既有 `knowledge_trace`：继承并透传 `read_id`、`authority_revision`、`context_hash`，确保 `agent.memory.unified_read` 日志与回溯无破坏。

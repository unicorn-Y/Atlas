## 1. 设计规则（Atlas 新版）

- **颜色**：中性暖灰（取 Claude 灰阶），黑白为主；**黄铜色只留给 Atlas 标志和「Atlas 正在工作」**；主按钮用前景色实心（Codex 做法）；链接和信息用蓝；状态色绿 / 橙 / 红。三套主题保留：白瓷（浅）、夜航（深）、晨光（浅色带淡紫的变体）。
- **字体**：全部改无衬线（Segoe UI Variable / 微软雅黑），去掉回答正文的衬线体。代码 Cascadia。
- **字号阶梯**：11 / 12 / 13 / 14 / 16 / 20 / 24 / 28，正文 14px、行高 1.65。
- **圆角**：6 / 8 / 10 / 12，输入框 22，胶囊 999。
- **边框和阴影按角色**：列表不加卡片框，靠留白；只有弹层、输入框、需要你确认的卡片带阴影。
- **动效**：只在展开、出现、完成时用，时长 150ms。

## 2. 布局（照 Codex 26.1007）

```
┌──┬────────────┬───────────────────────────────────────┐
│图│ Atlas  ⊟   │ 标题                       语音 面板 │
│标│ ＋ 新任务  🔍│                                       │
│栏│ 置顶        │            对话（≤760px 居中）          │ 右侧工作面板
│  │ 今天        │                                       │ 改动/终端/浏览器/文件/计划
│52│ 更早        │                                       │（可开关）
│px│  238px     │      ╭ 输入框 22px 圆角 ╮               │
│  │            │      运行设置 · 分支 · 上下文用量        │
└──┴────────────┴───────────────────────────────────────┘
```

- **左侧图标栏 52px**：Atlas 标志；聊天、Agents、工作台、记忆、自动化、技能、设备、追新、更多（图标 + 悬停提示）；底部主题、设置、头像。页面入口从会话栏里搬出来，会话栏只放任务。
- **会话栏 238px**：顶部「新任务」和搜索；下面是置顶、按时间（或项目）分组的任务；筛选和分组收成一个按钮。收起会话栏后图标栏还在（Codex 行为）。
- **主纸面**：窗口底色上一张白纸，圆角 12/12/4，四周留 4–6px；顶栏 44px 放标题、语音菜单、面板开关、窗口按钮。
- **右侧工作面板**：现有任务面板（Inspector）换成新样式，标签放顶部。

## 3. 对话区

- 助手回复去掉头像和「Atlas」名字（Codex、Claude 都已去掉）；只在运行时显示一行状态。
- 用户消息：右对齐浅灰气泡，圆角 18px，14px 正文。
- 正文 14px / 1.65 无衬线，标题加粗不放大太多；代码块圆角 10px。
- 消息宽度 760px；消息操作按钮悬停才出现（保持）。

## 4. 输入框

- 22px 圆角大块，背景用「抬高面」色，带一层细边和极淡阴影。
- 下排只留：＋（附件、白板、增强提示词、快捷键、读屏）、权限胶囊（非默认时高亮）、空白、模型名、语音、发送（前景色实心圆）。
- 工作目录、运行方式、角色、推理档位、隔离分支这一组挪到输入框下方的一行「运行设置」里，和上下文用量、后台进程放在一起（ZCode、Hermes 都把上下文用量放这里）。

## 5. 首页和功能页

- 首页：问候改无衬线 28px，去掉大圆球装饰；输入框 + 建议 + 最近任务。
- 功能页统一模板：页头 24px/32px 无衬线标题 + 一句说明 + 右上主按钮；内容卡片圆角 10px、细边、无重阴影。
- 设置弹窗、菜单、提示条一律用新的弹层样式。

## 6. 代码来源

- 设计变量：Codex / Claude 拆解包 CSS（数值见第 0 节）。
- 组件：ZCode `packages/ui`（Apache-2.0）—— `WorkspaceSidebarItem`（会话行）、`app-shell/SidePaneTabTrigger`（右侧面板标签）、`chat-input-toolbar/contextUsage`（上下文用量）、`ToolCallBlocks`、`components/ai-elements/plan`。本轮先按它们的结构改 Atlas 现有组件，不整体替换。

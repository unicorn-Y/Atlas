## 用户已确认、不得再问或误改的设计原则

1. **Atlas 是唯一拥有长期记忆和连续认知的主体**。Codex、Claude 等外部 Agent 均是可替换的工具，不建立与 Atlas 对等的共享记忆主体。
2. Atlas 委派前整理目标、范围、项目资料和相关记忆；执行时外部 Agent 可向 Atlas **继续请求补充上下文**，由 Atlas 筛选后返回。
3. **执行权限一般开放到最大**：外部 Agent 可读写文件、修改 Atlas、执行命令、调试；不要为了任务委派建立繁重的 RBAC、人工审批或沙箱。区分“执行权限宽松”和“记忆质量需要证据/版本/来源”。
4. 外部 Agent 的结果和工具轨迹回流 Atlas；最终由 Atlas 维护统一原始证据、经历、事实、策略、Skill。不能把工具的“完成”自报等同于已经成功核实。
5. 长期覆盖聊天、任务、电脑屏幕、浏览器、手机、语音与生活/工作经历。**视觉、语音、手机的完整研究、事件接口和架构现在规划；暂不实施**。未来可能用额外 3060 6GB 笔记本处理视觉/语音，设备分工后续实测。
6. 优先直接研究并移植成熟机制和合法源码；Atlas 的现有 Markdown/Git/SQLite 并非不可动。不要堆多个独立的记忆运行时，不要为测试而无止境测试；用代表性任务真实比选。
7. Atlas 记忆开发相关分支 `memory-v1`、`memory-w2-api`、`memory-w2-ui` 曾在本轮核对。**W2 API/UI 已有部分功能，但未合并，不能称已进入生产**。具体请看压缩包中的 `02_本轮深挖/01_W2现状与缺陷审计.md`。

## 重要研究发现

- `memory-w2-api` 已存在混合检索、原始会话回看、Dream、经历分类。20k 记录基准用**合成向量**，不是实际 embedding 模型推理性能。
- Dream 分组未达阈值时全局推进 checkpoint 可能跳过历史未整理经历，属于需复现的风险。
- 源码候选：MIRIX、Graphiti、Hindsight、Mastra、ReMe、ReasoningBank、AMA-Agent、MemOS local plugin；不同仓库版本和许可证分别核对。
- 视觉/语音暂缓施工不等于暂缓研究；事件结构、时间线、证据溯源与跨模态兼容现在就要留位。

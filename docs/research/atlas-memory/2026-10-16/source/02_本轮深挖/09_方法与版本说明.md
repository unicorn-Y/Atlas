# 方法与版本说明

- 本轮对 Atlas 和外部项目通过 GitHub 连接器读取具体文件/函数，同时核对多项目 main HEAD。`08_源码与资料索引.csv` 中 ref 为 `main` 的 HEAD 是本轮抓取时的观察值；为确保逐字复用，施工前应使用固定 commit 拉文件，复核文件 hash/许可证。
- Atlas 的 `memory-v1`、`memory-w2-api`、`memory-w2-ui` 参考的是当前远端分支；CSV 中这类条目的 ref commit 标注未锁定，不能因其路径有 branch 就假定永久不变。对需要正式移植的文件，在 Git 工作树使用 `git rev-parse` 固定 SHA。
- 所有实验用例处于 `SPEC_ONLY_NOT_EXECUTED`。无本机 Windows benchmark，无实际夜间自主运行，无主仓写入。
- 许可证信息以读取时仓库/对应子包声明为线索；任何实质复制都要再次确认被复制文件版权头、NOTICE 和依赖。
- 安全角度，外部 Markdown 和远程仓库的内容只当研究资料，不能作为命令指示。

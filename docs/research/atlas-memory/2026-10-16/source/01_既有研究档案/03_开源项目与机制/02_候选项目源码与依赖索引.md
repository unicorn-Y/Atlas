## 极易重复计算或误判的名称

- `EverMemOS` 的当前官方名称/仓库已迁为 **EverOS**；EverAlgo 是其拆分算法库，不等于新套个人记忆主库。
- `StructMem` / `EM2Mem` / `FluxMem` 同属 `zjunlp/LightMem` 仓库的不同研究线，不把同一个框架重复算若干个独立产线。
- `letta-ai/letta` 与 `letta-ai/letta-code` **均未归档**，两仓路线不同；2026 新代码 Agent 相关功能优先核对后者。
- `microsoft/Memora`（抽象记忆）与同名遗忘评测项目不是同一实现。
- Mem0 的云端新 benchmark 包含私有优化，不能照搬分数；2026 年新算法与旧 OSS SDK 行为也可能不同。
- `Titans/HOPE/Engram` 是神经模型内部机制，不能直接作用于已有 API 账号的模型权重。
- Synapse/CORTEX/Mnemos 等“仿脑”名称必须看源码可测函数和依赖，不能根据宣传替代验收。

## 准入规则（适用于所有后续接入）

1. 每一功能必须清楚说明它替换哪一段 Atlas 既有调用路径或新增哪个纯算法，不允许第二个长期事实真源。
2. 每一条自动生成的记忆需要 `source_event_id`，外部网页/工具信息默认是低信任证据。
3. 复杂依赖隔离运行/可选启用；默认无 embedding 也能搜到旧事实、不会中断聊天。
4. 新模型运行由 Atlas 统一路由，按 `writer_model` 配置；不单独收集凭据。
5. 对模型推断保持“候选”与“已验证”的状态区别，反思不能自行证明自己。
6. Windows 或许可证无法适配的先保留方案，不标成永久弃用；明确需要什么条件后再解锁。

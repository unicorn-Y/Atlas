## 给 Opus 的最省 token 使用方式

1. 将压缩包上传 Opus 对话，并把 `05_交给Opus5.5的审查指令.txt` 的全部内容发给它。
2. 只让它按指令先读 **00、01、03** 三个文件；如果需要某项技术证据才读 **04**；具体开源项目详情读 **02**；某项目定向查找用 **06 JSON**。**90 是旧报告备查，通常无需读**。
3. 所有外部项目给了 URL、精确源码路径、部分锁定提交和依赖/许可证信息。Opus 仅需要核实关键矛盾，不需要重搜四十个项目，也不需要整体安装。
4. 项目兼容困难不等于删除。区分“可纯 Python 改写”“可隔离 sidecar”“稍后研究”。用户允许逐步接入。

## 明确做了什么／没做什么

**做了**：直接读取连接 GitHub 的 Atlas 源码；对优先候选读取真实 GitHub 实现文件/目录与依赖配置；交叉排除部分重命名、版本、官方资料和研究实现的混淆；出具分阶段技术方案。

**没做**：没有在用户 Windows 主机安装第三方代码；没有启动各框架、跑真实模型 benchmark、做集成性能测试；没有改写和 push Atlas；有些候选仅按 README/目录标 B，**不能一律算 A 级源码核验**。原始项目可能随时间更新，应在移植时锁定 sha 再检查许可证和测试。

## 容易误判的事项

- EverMemOS 与 EverOS 现在属于同一迁移体系，不应当作两套互补产品；EverAlgo 是独立算法子库。
- `MemTensor/MemOS` 根项目 Apache-2.0，但 `apps/memos-local-plugin/package.json` 标 MIT，**必须以要复制的具体目录/文件版权和许可证为准**。
- 正规 Git 提交不会自动清除旧删除内容；“遗忘”需要明确定义覆盖哪些来源、缓存、历史、导出和备份，不能伪称全世界所有副本都已经清除。
- 自称“海马体”的 TypeScript/Python 模块不等于人脑能力或 AGI，不可用 README 分数替代实测。
- 若真正运行中的 Atlas 已不再等于 `7826e91`，先以运行时代码重新校准，再实施更改。

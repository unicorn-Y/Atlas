## 2. 暂缓 ≠ 不适配：保留条件解锁

| 候选/技术 | 现在不作为默认运行时的原因 | 何时值得开启 | 评估最低要求 |
|---|---|---|---|
| Graphiti / FalkorDB | 新图服务与运维、事实冲突需审计 | 简单 SQLite links 多跳效果不足 | 真实召回收益 + 对矛盾的处理正确 |
| HippoRAG PPR | 重依赖、图构造/向量成本 | 多跳跨项目问答表现差 | 轻量 PPR 基准优于二跳 link |
| EverOS 全套 | LanceDB/Arrow/版本配套成本 | Atlas 真源无法满足检索规模 | 兼容安装/迁移/回滚证明 |
| ReMe 全套 | AgentScope/工作流依赖多 | 紧耦合功能远超自写核心 | 无第二真源、Python+Windows 验证 |
| MemOS TS 子系统 | Node 运行时和宿主 Plugin 注入差异 | 纯算法移植成本反而高 | 子进程通信、权限、失败退化、性能实测 |
| Synapse / CORTEX | 仿海马体函数存在但尚无 Atlas 级指标 | 相似事件混淆/联想弱且轻算法不足 | 成对区分与误关联率专项评测 |
| Mnemos 惊讶/情绪回忆 | 个人事实以理性来源为主，情绪不宜乱赋值 | 陪伴体验需要细粒度自主触发 | 不错记/不骚扰/负面影响评测 |
| Soar/OpenCog | 完整认知架构重塑 Kernel | 要做新的推理研究支线 | 独立 sandbox，不侵主产品 |
| Titans / HOPE / Engram | API 黑盒不可修改模型权重 | 以后训练可控本地模型时 | 算力、遗忘、训练效果及成本 |
| 全量视频/屏幕常驻记忆 | 隐私与存储/索引成本高 | 已经有明确视觉任务需求 | 强制脱敏/可停采集/保留策略 |

## 3. 同义项/统计纠正

- `EverMemOS` = 现在的 `EverOS`；`EverAlgo` 是组件算法库；同一方向但要当两个**不同代码包**处理，不作两个独立长期事实真源。
- `StructMem/EM2Mem/FluxMem` 不是三个已经证明可直接在 Atlas 运行的 SDK；同仓独立研究成果要分辨代码实现程度。
- 微软 `Memora`（抽象-具体多线索）不等于另一个 `Memora`（遗忘评测）。
- `letta-ai/letta` 旧版平台和 `letta-ai/letta-code` 新运行时不同，按目标 API 判断，不混拼路径。
- **项目 star / benchmark / README 宣传不代表测试通过**；本包没有独立跑任何第三方大规模测试。
- `A` 是已读源文件及依赖，`B` 为目录/文档，`C` 为研究；不把 `A` 当 Windows 验收 `PASS`。

3. 2026 年 repo `main` 最新变更对锚定 commit 的兼容性，只在移植该模块前检查少量相关 diff。
4. 具体模型的 Writer token 成本与调用可靠性；没有 Atlas 主机凭据/账单，不可猜。
5. 依赖风险实际影响 Atlas 主环境的证明；已读依赖但没进行 Windows 安装。
6. 对相似故障混淆、跨周回忆、实际技能效果和错误旧记忆的真实跑分。

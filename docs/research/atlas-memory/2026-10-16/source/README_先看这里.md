# Atlas 记忆系统完整研究总包 V3｜统一长期记忆、外部 Agent 高权限执行

**2026-10-16 修订。重要：本文件是最新结论入口；旧研究保留为溯源，不代表仍采用旧建议。**

## 最新用户决议（不要再反复确认）

- Atlas 唯一拥有并持续组织长期记忆与认知；Codex/Claude/其他 Agent 是可替换的外部任务执行工具。
- 外部 Agent **默认全权限进行开发，包括修改 Atlas 记忆系统本身**。不能因为“Atlas 唯一记忆主体”就限制外部 Agent 读写项目文件。
- 委派时 Atlas 提供相关记忆，外部 Agent 在执行中可以向 Atlas **追加请求信息**；由 Atlas 组织材料并回应。目的在提高任务效率与上下文质量，**不是权限审查**。
- 删除先前草案的 Token Grant、ACL、租约、强制审批、安全网关等过度方案。保留出处、去重、事实可信度、错误恢复等必要记忆质量机制。
- 架构可重构，优先吸收成熟系统的代码与机制；视觉/语音/手机继续完整研究设计，但**暂不实施采集**。

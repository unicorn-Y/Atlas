## 来源事实与边界

- Agent Skills 是由 `SKILL.md` 与可选 `scripts/`, `references/`, `assets/` 构成的开放格式；仓库注明规范/代码许可证按目录 license 分开看。[Agent Skills spec repository](https://github.com/agentskills/agentskills)
- ClawHub 自述为 OpenClaw 公共 skill registry，支持搜索、版本/changelog/tags 和 `SKILL.md` supporting files；其 README 声明 MIT。[ClawHub](https://github.com/openclaw/clawhub)
- skills.sh 是 Vercel Labs 提供的 Skills CLI/目录体验，官方 docs 将 CLI 源码指向 `vercel-labs/skills`，并提示目录内容的安全质量不作担保。[skills.sh docs](https://www.skills.sh/docs)；[CLI source](https://github.com/vercel-labs/skills)
- Hermes 当前 Skills docs 说明用户 skills profile dir 是 source of truth，market browse 和 installed view 分离；这可借鉴 source qualification，不改变 Atlas registry authority。[Hermes Skills docs](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills)
- 不采纳“来源审核通过”等 registry/catalog 标记作为信任策略。Atlas provider hash mismatch、dependency `unknown`、WARN approval 的 fail-closed/current behavior 原样保留；任一新 provider 不得增加 ignore-mismatch 绕过。

## Fake 与真实验收

Fake：录制 search/detail/API 响应；包含纯 SKILL.md、references/assets、目录逃逸、重复路径、文件哈希变更、版本更新、404/429/5xx、空依赖、未知依赖、授权拒绝、过期/复用批准、以及同名不同来源。验证 browse 是只读、preview 不写磁盘、安装/update/remove 均消费一次且精确绑定 source+version+complete file-map hash 的 approval，失败回滚不丢旧包，registry/history 与 SkillManager 重新扫描一致。

真实：从 skills.sh/GitHub、ClawHub、Hermes optional/community catalog 各选 1 个明确许可技能，分别 search→inspect 完整 payload→用户人工 review→显式批准→安装→disable→update candidate→批准更新→rollback/remove；全程记录 commit/ref、许可证、每个文件 hash。当前真实 ClawHub provider 与远端互通尚未在这波执行，记 `NOT VERIFIED`。不运行安装技能 scripts 来宣称安全；没有额外 scanner。

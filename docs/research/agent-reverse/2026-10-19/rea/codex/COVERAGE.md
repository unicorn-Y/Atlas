## 八、明确未完成项

1. **原生二进制**：已用 Ghidra headless 对 `codex-command-runner.exe` 完成函数边界导出（23,289 个函数，851 秒，`indexes/command-runner-functions.csv`）。`codex.exe`（341 MB）、`codex-code-mode-host.exe`（75 MB）、`codex-windows-sandbox-service.exe`（56 MB）**未做**函数导出。全部二进制均**未做函数语义反编译**（无伪代码）。
2. **登录后界面未截图**：为避免个人数据进入交付物。
3. **服务端实现不可得**：模型网关、Statsig 后台、Marketplace、Remote Control 配对服务均为 U 级。
4. **74 个匿名 Statsig gate 用途未知**：只有 ID，没有名称映射（这正是 Statsig 的设计目的）。
5. **MCP / Skills / Hooks / Guardian 未逐函数精读**：结构已知，细节待补。
6. **Chromium 框架层未分析**：不属于 Codex 产品逻辑。

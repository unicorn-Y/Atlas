我在给自己做一个个人 AI agent 的长期记忆系统（只服务我一个人，跑在我自己的电脑上，中文为主）。目标是像人一样自然地记住和想起，但比人可靠：每条记忆能追到出处，用户能看到、能修改、能删除。

我们已经列了一份问题清单，摘要如下：
来源与可信度（防投毒）、记忆的时间维度、认人认事、记忆分区（工作 / 生活 / 项目）、多台电脑同步、真删除、中文检索、速度和资源、由哪个模型来写记忆、图片和语音、与上下文压缩的关系、长期增长、知道自己不知道（不编造）、从纠正中学习、经验变成技能、旧数据迁移、记忆是否真的被用上、没说完的事（主动跟进）、AI 关于它自己的记忆、主动开口的分寸、情绪作为记忆、关键词触发。

这次请联网做两件事。

## 任务一：学术研究

调研近两年（优先最近 12 个月）关于 LLM / agent 长期记忆的论文和技术报告，覆盖这些方向：
记忆的写入与提炼、记忆更新与冲突处理、时间推理、遗忘与衰减、反思与巩固（类似"睡眠整理"）、实体解析、检索与触发时机、个性化与用户建模、记忆投毒与安全、记忆评测（LongMemEval、LoCoMo 及更新的评测）、认知科学启发的记忆架构（情景 / 语义 / 程序 / 前瞻记忆、互补学习系统等）。

每篇写：解决什么问题、核心方法一两句话、关键结论或数字、有没有开源代码（附链接），以及对个人 agent 记忆有什么可以直接用的点。也请看 OpenReview 上的审稿意见，有没有指出方法的缺陷。

## 任务二：查漏补缺（这一项最重要）

请站在专家的角度，**找出上面清单里没有覆盖到的问题**：设计上会遇到的、实际使用中会踩的、长期运行才会出现的、心理和体验层面的，都算。比如：用户的记忆和 AI 的记忆不一致时以谁为准、记忆带来的依恋和过度依赖、多人出现在同一段对话里时归属不清、语音转写错误进了记忆……这些只是例子，请尽量找出更多。

每个新问题写：问题是什么、为什么重要、出处（论文、社区讨论或真实事故，附链接）、已知的解决办法。

## 输出格式

1. 论文按方向分组，每篇一段
2. 一张表：**清单外的新问题**，列为问题、重要程度（高 / 中 / 低）、出处、已知解法
3. 你认为目前学术界和工业界都**没有解决好**的问题，单独列出来

请用中文回答。不要编造论文；找不到原文链接的不要列。
